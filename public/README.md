# Mellow — Public Assets Folder

Drop any reference images here! The app automatically serves everything in this folder.

## How to use

- Drop inspiration images for the cat, room, or other visuals here
- Access them in the app at: `http://localhost:3000/public/your-image.jpg`
- Supported formats: JPG, PNG, SVG, WebP, GIF

## Suggested reference categories

- `cat-reference/` — cat illustration inspiration
- `room-reference/` — cozy room / lofi room aesthetic references  
- `ui-reference/` — app UI inspiration
- `collectibles/` — collectible item ideas

The server will serve all files in this folder automatically.
